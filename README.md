# NeuroGest - BCI Game Controller

Brain-Computer Interface system that classifies EEG motor-imagery 
signals to control a real-time Pygame game.

## Tech Used
- Python, Scikit-learn (SVM)
- MNE (EEG signal processing)
- Pygame

## Result
Achieved ~85-86% classification accuracy on PhysioNet EEG dataset.

Project code is in the zip file (bci_game.zip).
